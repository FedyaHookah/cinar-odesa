# Çinar: сайт-меню ресторану (PHP)

Одна сторінка з меню: логотип-листок чинара, вступна заставка, пошук страв, вкладки категорій, мови UA / EN, фото біля кожної страви, склад сетів.

## Запуск

Потрібен PHP 8.1 або новіший.

- XAMPP: скопіюйте папку `cinar` у `C:\xampp\htdocs\` і відкрийте `http://localhost/cinar/`.
- Або в терміналі: `cd cinar`, потім `php -S localhost:8000`, адреса `http://localhost:8000`.

## Де що змінювати

| Файл | Що там |
| --- | --- |
| `data/menu.php` | категорії, страви, ціни, ваги, склад сетів (є приклади прямо у файлі) |
| `config.php` | назва, підпис, вступний текст, тексти заставки, режим заставки |
| `assets/style.css` | кольори (змінні на початку файлу) і шрифти |
| `assets/logo.svg` | логотип, він же іконка вкладки браузера |
| `assets/img/menu/` | фото страв |

## Фото страв

Кожна страва має поле `'img'` у `data/menu.php`, наприклад `'img' => 'baranina-kare'`. Сайт шукає фото в `assets/img/menu/` за цією назвою: `baranina-kare.jpg`, а якщо його немає, то `.jpeg`, `.webp` або `.png`.

Зараз там лежать тестові картинки з назвою страви та іменем файлу. Щоб замінити, збережіть справжнє фото **з тією самою назвою** поверх тестового. Нічого більше міняти не треба. Якщо фото для страви ще немає, показується загальна заглушка `assets/img/placeholder.svg`.

Порада щодо фото: квадратні або 4:3, ширина від 600 px, формат `.jpg` або `.webp`. На сайті вони обрізаються по центру.

## Нова страва

Додайте рядок у потрібну категорію в `data/menu.php`:

```
['img' => 'nazva-fajlu', 'n' => ['Назва українською', 'Name in English'], 'p' => 250, 'w' => '300 г'],
```

Потім покладіть фото `nazva-fajlu.jpg` у `assets/img/menu/`.
